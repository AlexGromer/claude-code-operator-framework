## Review Checklist

### Freshness Check
- [ ] Source has been updated within last 12 months
- [ ] OR: Source contains timeless/evergreen content
- [ ] Content reflects current best practices (not outdated)
- [ ] No broken links or deprecated information

### Authority Check
- [ ] Source author/organization is identifiable
- [ ] Author has recognized expertise in domain
- [ ] Source is cited by other reputable sources
- [ ] OR: Source is official documentation

### Relevance Check
- [ ] Content directly relates to selected domain
- [ ] Content is at appropriate technical level
- [ ] Content fills gap in current source coverage
- [ ] Content is not redundant with existing sources

### Accessibility Check
- [ ] Source is publicly accessible (or access method documented)
- [ ] No region restrictions / geoblocking
- [ ] Content is in English or Russian (or translation available)
- [ ] No excessive paywalls or barriers

### Quality Check
- [ ] Content is accurate and well-researched
- [ ] Content is well-organized and structured
- [ ] Examples/code samples are tested and working
- [ ] No obvious errors or misinformation

### Security Check
- [ ] Source URL uses HTTPS (or HTTP for localhost/development)
- [ ] No malicious content detected
- [ ] Domain reputation is clean (no spam/phishing history)
- [ ] Source does not require excessive permissions
