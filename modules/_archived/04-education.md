## Project-Specific: Agent Development Learning Path

Applicable when building or teaching about Claude Code agents in this project.

**Beginner (0-3 months):**
1. LLM Basics — Prompting, temperature, tokens
2. Tool Use — Function calling, ReAct pattern
3. Context Management — Chunking, retrieval
4. Simple Agents — Single-turn, no state

**Intermediate (3-6 months):**
5. Multi-Turn Agents — Conversation, memory
6. Orchestration — Sequential, parallel subagents
7. RAG — Vector databases, embeddings
8. Evaluation — Metrics, testing, benchmarks

**Advanced (6-12 months):**
9. Advanced Orchestration — LangGraph, state machines
10. Fine-Tuning — LoRA, RLHF
11. Production Deployment — Scaling, monitoring
12. Safety & Alignment — Red teaming, jailbreak defense
