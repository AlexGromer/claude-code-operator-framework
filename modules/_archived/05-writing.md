## Project-Specific: Russian Academic (ВКР) Structure

Use when writing Russian bachelor/master thesis (diploma work).

```
Введение:
  - Актуальность — почему тема важна сейчас
  - Степень разработанности — что уже исследовано
  - Цель работы — главная цель
  - Задачи — конкретные задачи для достижения цели
  - Объект исследования — что изучаем
  - Предмет исследования — какой аспект объекта
  - Методы исследования — какие методы используем
  - Научная новизна — что нового привносит работа
  - Практическая значимость — польза для практики
  - Структура работы — описание глав

Глава 1. Теоретическая часть
  1.1 / 1.2 / 1.3 + Выводы по главе 1

Глава 2. Практическая часть / Методология
  2.1 / 2.2 + Выводы по главе 2

Глава 3. Результаты и анализ
  3.1 / 3.2 + Выводы по главе 3

Заключение:
  - Основные результаты
  - Достижение цели и задач
  - Практические рекомендации
  - Перспективы развития

Список использованных источников [ГОСТ Р 7.0.5-2008]
Приложения
```

```
# Веб-ресурс

```
