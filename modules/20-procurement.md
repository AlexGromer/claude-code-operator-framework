## 1. 44-ФЗ: Процедуры и пороги

| Процедура | Порог | Срок | Примечание |
|-----------|-------|------|------------|
| Открытый конкурс | >10M RUB | 30+ дней | Наиболее прозрачный |
| Электронный аукцион | 3M–10M RUB | 7–20 дней | Только цена, через ЕИС |
| Запрос котировок | <500K RUB | 5 дней | Упрощённое сравнение цен |
| Запрос предложений | <10M RUB | 10 дней | Срочность, спецкритерии |
| Единственный поставщик | Любая | Сразу | Только исключительные случаи |

**Платформа**: zakupki.gov.ru (ЕИС)

**Обязательные требования**:
- Проверка РНП (Реестр недобросовестных поставщиков)
- Обеспечение заявки: 0.5–5% от НМЦК
- Обеспечение исполнения: 5–30%
- Техническое задание + обоснование НМЦК
- Неустойка за просрочку: 1/300 ставки ЦБ в день
- Акт приёма-передачи при сдаче

## 2. 223-ФЗ vs 44-ФЗ

**Сфера 223-ФЗ**: Госкорпорации (Ростех, Росатом, Роскосмос), компании с госдолей >50%, естественные монополии.

| Аспект | 44-ФЗ | 223-ФЗ |
|--------|-------|--------|
| Процедуры | 5 строго регулированных | Любые (по Положению) |
| Ценообразование | НМЦК обязательна + обоснование | Гибкое |
| Изменение контракта | Ограничено, через ФАС | По Положению о закупках |
| Контроль ФАС | Полный | Ограниченный |
| Отчётность | Детальная в ЕИС + ФАС | Планы + итоги в ЕИС |
| Пороги | Жёсткие | Задаёт заказчик |

**Положение о закупках** — обязательный документ (публикуется на zakupki.gov.ru): виды процедур, критерии оценки, антикоррупционные меры.

**Преимущества 223-ФЗ**: быстрее (переговоры), гибче критерии, проще поправки к контракту.

## 3. Техническое задание (ТЗ) — структура по ГОСТ

```markdown
# ТЕХНИЧЕСКОЕ ЗАДАНИЕ

## 1. ОБЩИЕ СВЕДЕНИЯ
- Наименование закупки, Заказчик, НМЦК, Сроки поставки

## 2. ОБЪЕКТ ЗАКУПКИ
- Наименование, количество, функциональные/технические/качественные характеристики

## 3. ТРЕБОВАНИЯ К ОБЪЕКТУ ЗАКУПКИ
### 3.1 Обязательные
- Соответствие ГОСТ, ТР ТС, сертификация, документы качества
### 3.2 Функциональные характеристики
- Технические параметры (min/max), эксплуатационные, совместимость
### 3.3 Эксплуатационные
- Производительность, надёжность (MTBF, гарантийный срок), энергопотребление

## 4. ТРЕБОВАНИЯ К ПОСТАВЩИКУ
- Опыт аналогичных контрактов (не менее X лет), квалификация, сервисная служба

## 5. ПОРЯДОК И СРОКИ ПОСТАВКИ
- Место, сроки ввода в эксплуатацию, условия приёмки

## 6. ГАРАНТИЙНЫЕ ОБЯЗАТЕЛЬСТВА
- Срок (не менее X мес.), условия обслуживания, сроки устранения неисправностей

## 7. КРИТЕРИИ ОЦЕНКИ ЗАЯВОК
- Цена (40–60%), качество/функциональность (20–30%), квалификация/опыт (10–20%), сроки (5–10%)

## 8. ОБОСНОВАНИЕ НМЦК
- Метод: анализ рынка / тарифный / проектно-сметный / затратный
- Источники информации (не менее 3 для метода анализа рынка)
- Расчёт
```

## 4. Расчёт НМЦК

| Метод | Когда | Суть |
|-------|-------|------|
| Анализ рынка | Основной | Минимум 3 коммерческих предложения / прайс-листа |
| Тарифный | Регулируемые цены | Официально утверждённые тарифы |
| Проектно-сметный | Стройка/реконструкция | По сметной документации |
| Затратный | Нет рыночных аналогов | Себестоимость + прибыль |

**Для метода анализа рынка**: запросить КП у ≥5 поставщиков, использовать ≥3 ответа с сопоставимыми условиями (объём, сроки, качество).

## 5. IT-специфика закупок

| Категория | 44-ФЗ / 223-ФЗ — ключевые требования |
|-----------|--------------------------------------|
| Оборудование | Подробные характеристики (CPU, RAM, диски), класс энергоэффективности |
| ПО (лицензии) | Тип лицензии (постоянная/подписка), именные/конкурентные пользователи |
| SaaS / облако | Локализация данных (ФЗ-152), SLA, резидентность вендора |
| Консалтинг | Квалификация персонала (сертификаты, опыт, штат) |
| Разработка ПО | Права на ИС, критерии приёмки, срок техподдержки |
| Сопровождение | SLA по времени реакции/устранения, эскалация |

## 6. Импортозамещение

**Реестр российского ПО**: https://reestr.digital.gov.ru

**Правила**:
- Госзакупки >300K RUB (ПО): обязательно российское ПО при наличии аналога
- Иностранное ПО: только с письменным обоснованием отсутствия российского аналога

| Категория | Российский продукт | Реестр | Иностранный аналог |
|-----------|-------------------|--------|-------------------|
| ОС | Astra Linux | #751 | Ubuntu, RHEL |
| СУБД | PostgreSQL Pro | #205 | PostgreSQL, Oracle |
| Офис | МойОфис | #3916 | MS Office |
| Виртуализация | KVM (RedOS) | #11086 | VMware vSphere |
| Антивирус | Kaspersky | #38 | Symantec, McAfee |
| SIEM | MaxPatrol | #3867 | Splunk, QRadar |
| ERP | 1С:ERP | #1 | SAP, Oracle ERP |
| Почта | CommuniGate Pro | #2719 | MS Exchange |

## 7. Compliance в закупках

### ФЗ-152 (если вендор обрабатывает персональные данные)
```
☐ Вендор зарегистрирован в РФ или имеет российское юрлицо?
☐ Данные хранятся на территории РФ?
☐ Договор на обработку ПДн включён в контракт?
☐ Вендор подал Уведомление в Роскомнадзор?
☐ Процедура уведомления об инцидентах определена?
```

```markdown
## ТРЕБОВАНИЯ ПО БЕЗОПАСНОСТИ ИНФОРМАЦИИ (в ТЗ)
1. Класс защищённости: [K1/K2/K3/K4]
2. СЗИ с сертификатом ФСТЭК России (обязательно для K1–K2)
3. Меры по Приказу ФСТЭК №239: идентификация, управление доступом,
   регистрация и учёт, защита носителей информации
```
